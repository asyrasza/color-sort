# Color Sort

A bead-sorting puzzle in a single HTML page. Move beads one at a time between rods until each rod holds only one color.

- 5–15 colors, with one rod per color plus one empty spare rod
- Undo, a move counter and a timer
- 10 save slots, stored in your browser
- Optional symbols on the beads for color-blind players

Play it at https://asyrasza.github.io/color-sort/
